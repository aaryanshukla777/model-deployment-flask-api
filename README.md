# Iris Classification Model Deployment

This project covers building a machine learning model for Iris flower classification and exploring how a trained model can be used for predictions.

## What I worked on
- Loaded and explored the Iris dataset.
- Prepared the data for model training.
- Built and evaluated a classification model.
- Explored the steps involved in making model predictions.

## Tools used
- Python
- Jupyter Notebook
- Pandas
- Scikit-learn

## Files
- `iris_classification_model_deployment.ipynb` — notebook containing the analysis and model workflow.
- `2. Iris Dataset.xlsx` — dataset used in the project.
